## Part 2: Target Tasks for FL-02 through FL-04

I have selected three specific recurring tasks from my audit to refine across the upcoming assignments:

### Target Task 1: Technical Workshop Copywriting
* **Task:** Drafting promotional copy for technical student workshops (e.g., machine learning, Figma, photography).
* **Classification:** Delegate to AI with review
* **Definition of "Done Well":** The final copy must capture the exact event details (date, prerequisites, key takeaways) in under 200 words, hit a professional yet engaging tone for university peers, and require less than 3 minutes of human editing.

### Target Task 2: Data Cleansing & Pandas Analysis Scripts
* **Task:** Writing data processing scripts for EDA (Exploratory Data Analysis) and dataset preparation.
* **Classification:** Delegate to AI with review
* **Definition of "Done Well":** The generated Python/Pandas code executes without syntax errors on first run, correctly handles null values/edge cases, and includes clean docstrings and inline comments.

### Target Task 3: n8n / Gumloop Workflow Node Logic Design
* **Task:** Structuring JSON payloads and conditional branching logic for automated AI agents.
* **Classification:** Collaborate with AI
* **Definition of "Done Well":** The AI produces a valid JSON structure or step-by-step logic map connecting API inputs to outputs, reducing setup time by at least 50% without dropping required data fields.
